# ゲーム概要

営業マンが綱渡りをするゲーム

# 操作

矢印キーでバランスゲージを維持する、基本は左右のバランスを維持するがイベントによって上下にバランスをとることもある（優先）
joyコンでガイド線に合わせるように動かす（ゲームが遊べる状態になった後に追加で作る感じ）

# ゲーム性

ビルの間をロープで渡る
ロープの上でバランスを維持する（イベント中もイベント外でも常にバランスをとる）
イベントがランダムで発生（スナイパー＆マトリックス→スナイパーの赤い線が出てきて、飛んでくる弾を棒で弾く、そのあと棒が壊れて弾を避ける、その時マトリックスのワンシーンみたいにスローモーションで弾避けをする　紙が飛んでくる→遠くから紙が飛んできて画面に貼り付く）
イベントごとに視点が変化
バランスゲージを崩したり、時間内にJoyコンでガイド線に合わせれないとバランスを崩すモーションになりダメージを食らう
一定回数ダメージを蓄積するとゲームオーバーになる
ロープを渡りきるとクリア
被ダメージの回数によってクリアのエンディングが3つに分岐する
